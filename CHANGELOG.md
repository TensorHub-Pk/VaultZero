# Changelog

All notable changes to this project will be documented in this file.

## [4.0.0-beta] - 2026-02-27

### Added

- **Post-Quantum Cryptography (PQC)**: Integrated ML-KEM-768 (Kyber) and ML-DS for quantum-resistant data sharing and identity signatures.
- **Hybrid Key Exchange**: Standard X25519 combined with Kyber for future-proof security.
- **Steganographic Shield**: Robust threshold steganography engine for hiding encrypted data in images.
- **Native Shield (PWA)**: Desktop and Mobile installation support with 100% offline capability.
- **Audit Logs**: Tamper-evident local security logging and anomaly detection.
- **Panic Wipe**: Immediate local data destruction feature.
- **Session Lockdown**: High-security 48-hour session expiration policy.
- **Proactive Security Modals**: Automatic notification for session updates and reloads.

### Changed

- **Desktop Header Actions**: Redesigned as a vertically stacked group for "Wipe Data" and "Install App."
- **Status Indicators**: Unified security and version indicators with a pulsing blue/green dot aesthetic.
- **Mobile Navigation**: Improved responsiveness and navigation logic for smaller screens.
- **Resilience Rescue**: Added safety timeouts (8s) for app initialization on slow networks.
- **Branding**: Updated tagline to "Your Privacy, Sealed Permanently 😉".

### Fixed

- **Mobile Loading Hang**: Resolved a critical issue where the loader would get stuck on certain mobile browsers.
- **Network Timeouts**: Added abort signals to prevent fetch hanging on flaky connections.
